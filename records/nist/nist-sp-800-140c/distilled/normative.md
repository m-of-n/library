# NIST SP 800-140C — distilled

- **Role:** The maintained LIST of CMVP-approved security functions (cryptographic algorithms), by reference to the NIST FIPS/SP crypto standards.
- **Modifies / replaces:** ISO/IEC 19790 Annex C (replaced).
- **Structure:** A reference list, not narrative requirements; kept current as algorithms are approved/withdrawn.
- **Place in the stack:** FIPS 140-3 adopts ISO/IEC 19790 + 24759 and applies the CMVP modifications in the SP 800-140x series; **SP 800-140C** is one of those. See `fips-140-3` and `iso-iec-19790`.

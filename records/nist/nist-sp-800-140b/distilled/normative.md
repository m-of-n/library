# NIST SP 800-140B — distilled

- **Role:** Defines the content and tabular format of the cryptographic module security policy — the primary PUBLIC, auditable deliverable of a FIPS 140-3 validation. Directly realizes fips-140-3#security-policy.
- **Modifies / replaces:** ISO/IEC 19790 Annex B and ISO/IEC 24759 §6.14.
- **Structure:** Specifies required sections/tables of the security policy; the deliverable an auditor/consumer reads to confirm conformance.
- **Place in the stack:** FIPS 140-3 adopts ISO/IEC 19790 + 24759 and applies the CMVP modifications in the SP 800-140x series; **SP 800-140B** is one of those. See `fips-140-3` and `iso-iec-19790`.

# NIST SP 800-140 — distilled

- **Role:** The Derived Test Requirements (DTR): the Test Evidence (TE) / Vendor Evidence (VE) items a CMVP lab uses to test a module against FIPS 140-3. Contains the bulk of the testable ~shall statements (136).
- **Modifies / replaces:** ISO/IEC 24759 (test requirements).
- **Structure:** Testable requirements are expressed as TE/VE modifications keyed to ISO/IEC 24759 clauses; full sense requires ISO/IEC 24759 (paywalled).
- **Place in the stack:** FIPS 140-3 adopts ISO/IEC 19790 + 24759 and applies the CMVP modifications in the SP 800-140x series; **SP 800-140** is one of those. See `fips-140-3` and `iso-iec-19790`.

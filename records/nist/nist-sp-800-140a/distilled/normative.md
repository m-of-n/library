# NIST SP 800-140A — distilled

- **Role:** Additional vendor documentation requirements (VE additions) a module submission must provide.
- **Modifies / replaces:** ISO/IEC 24759 (vendor documentation).
- **Structure:** Small set of documentation modifications, formatted as additions to ISO/IEC 24759 vendor evidence.
- **Place in the stack:** FIPS 140-3 adopts ISO/IEC 19790 + 24759 and applies the CMVP modifications in the SP 800-140x series; **SP 800-140A** is one of those. See `fips-140-3` and `iso-iec-19790`.

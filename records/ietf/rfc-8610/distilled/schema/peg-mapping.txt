Appendix A is NORMATIVE, and this table is the reason the ABNF in
Appendix B is not the whole story: CDDL's "/" is a PRIORITIZED
choice, not ABNF's symmetrical one.  The appendix's lead-in, quoted
(source lines 2429-2431): "While PEG is only about characters, CDDL
has a richer set of elements, such as types and groups.
Specifically, the following constructs map:".

       +-------+-------+-------------------------------------------+
       | CDDL  | PEG   | Remark                                    |
       +-------+-------+-------------------------------------------+
       | "="   | "<-"  | /= and //= are abbreviations              |
       | "//"  | "/"   | prioritized choice                        |
       | "/"   | "/"   | prioritized choice, limited to types only |
       | "?" P | P "?" | zero or one                               |
       | "*" P | P "*" | zero or more                              |
       | "+" P | P "+" | one or more                               |
       | A B   | A B   | sequence                                  |
       | A, B  | A B   | sequence, comma is decoration only        |
       +-------+-------+-------------------------------------------+
---- END VERBATIM A-1 ----

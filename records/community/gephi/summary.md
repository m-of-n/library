# Gephi desktop documentation and project

## Overview

Gephi 0.11.3 is a desktop network-analysis application. Official sources document graph
interaction, layouts, filtering, metrics, weighted styling, Data Laboratory, Preview, and
timeline/dynamic-graph features. The source repository is dual-licensed under CDDL 1.0 or
GPLv3.

## Evidence used by RPT-0006

- Product page: https://gephi.org/desktop/
- Quickstart: https://gephi.org/quickstart/
- Repository and licenses: https://github.com/gephi/gephi
- Releases: https://github.com/gephi/gephi/releases
- The product's 100,000-node/1,000,000-edge figure is retained as an official project
  claim, not an independently verified benchmark.

## Applicability

Reference environment for Issue #10 layout, filtering, weighting, and graph/table/timeline
separation. It bears on no accepted decision in this record.

## Limits

Gephi is a desktop application rather than a browser visualization SDK, and the sources do
not document a threat-specific path review or AI proposal verdict workflow.

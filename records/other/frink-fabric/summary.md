# FRINK — FabRic Integrating Networked Knowledge (RENCI, Proto-OKN Theme 2)

|  |  |
|---|---|
| **Type** | repo (implementation) |
| **Source** | https://frink.renci.org/ |

## Overview

The OKN 'fabric': hosts domain graphs, exposes a federated SPARQL endpoint, each graph a named-graph URI with catalog metadata; provenance via identifier harmonization + best-practice graph construction.

## Applicability to tmodel

Concrete blueprint for federating multiple KGs under one endpoint with per-graph provenance and stable identifiers — the mechanism tmodel needs for attribution/governance and any OKN federation.
